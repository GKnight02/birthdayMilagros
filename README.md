# Feliz Cumpleaños, Milagros 🎂

Una pequeña historia animada en pixel art, hecha como regalo de cumpleaños.

## Ver en línea

👉 **https://gknight02.github.io/birthdayMilagros/**

## Cómo se juega

- Presiona **START** (o **Enter**) para comenzar.
- Toca la pantalla o presiona **Enter / Espacio** para avanzar los diálogos.

## Correr localmente

Es HTML, CSS y JavaScript sin dependencias: basta con abrir `index.html` en el navegador.

## Estructura

```
index.html       Página principal
css/style.css    Estilos
js/main.js       Escenas, personajes e historia
js/sprites.js    Sprites en pixel art
js/audio.js      Música y efectos de sonido (Web Audio, sin archivos externos)
```
